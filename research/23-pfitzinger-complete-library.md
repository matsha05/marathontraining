## Workout Type Definitions

| Abbreviation | Description | Pace |
|--------------|-------------|------|
| Recovery | Easy recovery jog | Very easy (2:00+ slower than MP) |
| GA | General Aerobic | Easy + strides, ~1:00-1:30 slower than MP |
| MLR | Medium-Long Run | Endurance pace, 45-90 sec slower than MP |
| LR | Long Run | Endurance pace, 45-90 sec slower than MP |
| LT | Lactate Threshold | 15K-HM pace (~30-45 sec slower than 10K) |
| VO2max | Intervals | 5K pace |
| MP | Marathon Pace | Goal marathon pace |
