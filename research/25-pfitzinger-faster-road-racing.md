## Workout Type Definitions

| Abbrev | Description | Pace |
|--------|-------------|------|
| End | Endurance run | 1:30-2:00 slower than 5K |
| GA | General Aerobic | Easy + strides |
| Prog | Progression run | Start easy, finish at LT |
| LT | Lactate Threshold | 15K-HM pace |
| VO2max | Intervals | 3K-5K pace |
| Speed | Short repeats | 1500m-Mile pace |
| HMRP | Half Marathon Race Pace | Goal HM pace |
